# Sparse-Aware RISC-V Vector Architecture for High-Performance Computing

## Objective
Evaluate RISC-V Vector Extension (RVV) performance on sparse workloads,
using Sparse Matrix-Vector Multiplication (SpMV).

## Midterm Deliverables
1. Study RVV and existing sparse-computing architectures.
2. Set up and validate the baseline RISC-V simulation environment.
3. Run baseline RVV execution on SpMV or an equivalent sparse workload.
4. Evaluate at least two sparsity levels.
5. Report execution time and performance.

## Project Structure
- docs/: Literature review and experiment notes
- src/: Source code
- workloads/: Input matrices and compiled programs
- scripts/: Build and experiment scripts
- configs/: gem5 configuration files
- results/: Raw simulation results
- plots/: Performance graphs

Environment verification in progress.
